Essentially smart brute-forcing a problem.

Two applications of DP:
- Finding an optimal solution (finding minima or maxima)
- Finding number of solutions

Supposedly you use DP when the problem can be divided into solvable overlapping subproblems. 

Tabulation:
- Start from the bottom and accumulate values to the top using a table.

Memoization:
- Store values in an array after calculation to avoid recalculation
