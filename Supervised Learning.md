Supposedly the most popular form of machine learning.

The concept of training a model using labelled data, each input has a corresponding correct output. Model is run on training data where it learns features and then is run on test data set. The model is then optimized using techniques like cross-validation & grid search to balance the bias and variance. 

Supervised Learning Classification (defined labels): Where the output is a categorical variable (yes or no).

Supervised Learning Regression (no defined labels): Where the output is a continuous variable (house prices).

Supervised ML Algos:
- Linear Regression (line fitting)
- Logistic Regression (used for binary outputs)
- Decision Trees (tree structure with decisions and outputs)
- Random Forests (multiple decision trees together)
- Support Vector Machines (SVM) (uses hyperplanes to split space)
- K-Nearest Neighbors (uses close past training data to predict)
- Gradient Boosting ()
- Naive Bayes Algorithm ()
All these models are trying to minimize a loss function, gradient descent?

Disadvantages:
- Overfitting
- Feature Engineering (having to extract relevant features manually for data?)
- Bias in Models
- Dependency on Labelled Data xd
