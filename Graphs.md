A non-linear data structure consisting of vertices and edges which both contain values denoted G(V, E).

Types of Graphs:
- Null Graph (if there are no edges)
- Trivial (only 2 vertex)
- Undirected (edges don't have directions)
- Directed (nodes are ordered pairs)
- Connected (you can get from one to any other node)
- Disconnected (you cant do ^)
- Regular (if every vertex is equal to K)
- Complete (every node connects to every other)
- Bipartite Graph (layers in a neural net)

Implementation: Can either be done with a Adjacency Matrix or Adjacency List. For the matrix, the rows and columns denote the vertices and the values denote the weight between the two nodes. For the adjacency list its a array of linked lists.



Types of search algorithms:
- Breadth First Search
